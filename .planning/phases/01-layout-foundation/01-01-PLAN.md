**1b. Fix dual bottom padding (ISSUE-4) — index.css**

The problem: On mobile (<768px), BOTH `.app-main` (line 879) AND `.page-container` (line 1576) add bottom padding with safe-area-inset-bottom. Pages using `page-container` get ~192px total bottom space (excessive). Pages NOT using `page-container` only get 92px from `app-main`. The fix is to apply bottom padding at `.app-main` level ONLY and remove it from `.page-container`.

In the `@media (max-width: 768px)` block starting at line 866:

- Keep `.app-main` bottom padding (line 879) but verify the value. The bottom nav is 56px content + 8px top padding + 8px bottom padding = ~72px. With safe area, use:
  ```css
  .app-main {
    margin-left: 0;
    padding-bottom: calc(80px + env(safe-area-inset-bottom));
  }
  ```
  Change from `92px` to `80px` — the MobileBottomNav is ~72px tall (48px min-height items + 8px top + 8px bottom padding), so 80px provides a small buffer. This is better than 92px which was slightly excessive.

In the `@media (max-width: 768px)` block starting at line 1573:

- Remove the `padding-bottom` line from `.page-container` (line 1576). Change:
  ```css
  .page-container {
    padding: 24px 20px;
    padding-bottom: calc(100px + env(safe-area-inset-bottom));
  }
  ```
  to:
  ```css
  .page-container {
    padding: 24px 20px;
  }
  ```
  The bottom padding is now handled by the parent `.app-main`, so `page-container` should NOT add its own. This prevents double-stacking.

**Also clean up the `!important` override at line 1257:**

The rule `.app-main__content > div { padding: 20px !important; }` at line 1257 exists to override inline `padding: '40px'` on the 10 legacy pages. After Task 2 migrates those pages to `page-container`, this rule becomes unnecessary. However, keep it for now as a safety net — it will be removed in a future cleanup phase once all pages are confirmed migrated. Add a CSS comment:
```css
/* TODO: Remove this override once all pages use page-container class (see Task 2 migration) */
.app-main__content > div {
  padding: 20px !important;
}
```
