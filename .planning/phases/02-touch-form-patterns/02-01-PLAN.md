  <name>Task 1: Add global mobile CSS rules for input font size and button touch targets</name>
  <files>src/Client/timesheets-web/src/index.css</files>
  <action>
In the existing `@media (max-width: 768px)` section around line 2038 (ISSUE 7: TOUCH TARGETS), enhance the mobile rules:

1. Add a global rule for ALL form inputs to use 16px font size on mobile to prevent iOS auto-zoom:
```css
input[type="date"],
input[type="number"],
input[type="text"],
input[type="email"],
input[type="tel"],
input[type="search"],
select,
textarea {
  font-size: 16px !important;
}
```
This overrides any inline style `fontSize: '14px'` without needing to change every JSX file.

2. Ensure the existing min-height: 44px rule covers all interactive button-like elements on mobile. Add:
```css
.page-container button,
.page-container [role="button"],
.page-container a.btn {
  min-height: 44px;
}
```

3. Add a rule for full-width buttons on mobile forms:
```css
.form-actions-mobile {
  flex-direction: column;
  gap: 12px;
}
.form-actions-mobile button {
  width: 100%;
  justify-content: center;
}
```

4. Add a body text minimum font size rule:
```css
.page-container p,
.page-container span:not(.material-symbols-outlined),
.page-container div {
  /* Body text minimum - handled by not going below 13px in inline styles */
}
```
NOTE: Do NOT add a blanket font-size rule on p/span/div as it would break intentional small labels (10px status badges, 11px labels). The 16px rule on inputs is sufficient since body text is already 13-15px in most places.

Do NOT change the existing touch-target or btn-icon rules. Append the new rules AFTER the existing ones in the same media query block.
